# Documentation contract

## Data sources
Document source type, system, endpoint/server/database where safe, consuming queries, authentication method, refresh method, gateway/connection, owner, environment and risks. Never record credential values.

## Power Query
For each query document source, load status, dependencies, parameters, transformations, joins, filters, grouping, calculated columns, type changes, error handling, destination, inferred grain and risks.

## Semantic model
For each table document type, purpose, source query, grain, key candidates, relationships, dates, calculated objects, hidden fields, hierarchies, row count if supplied and SCD readiness.

## DAX
For each material measure document business definition, expression, dependencies, context, total behaviour, format, risk and validation requirement.

## Report
For each page document audience, decision, visuals, measures, slicers, filters, drillthrough, bookmarks, navigation, controls and duplicated content.
