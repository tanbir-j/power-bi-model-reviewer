# ChatGPT runtime

Use an organisation-approved ChatGPT Business, Enterprise or Edu workspace. Business workspace data is not used for training by default, but this is not permission to upload secrets.

Prefer uploaded PBIP/TMDL/PBIR artefacts or a sanitised Power BI Service review pack. Run local scripts before loading source text into the reasoning context. Use web research for current domain benchmarking. Clearly distinguish deterministic extraction, visual inspection and inference.
