# Claude runtime

Use an organisation-approved Claude Team or Enterprise workspace. Do not use a personal Free, Pro or Max account for organisationally sensitive files merely because browser incognito or a private project is enabled.

Prefer a Cowork or Desktop working folder containing sanitised TMDL, PBIR, JSON, CSV and screenshots. Claude need not consume PBIX directly. Use a local extractor or Power BI Service/API workflow to create the review pack, scan and redact locally, then analyse only the sanitised folder.

Where code execution is available, run the bundled scanner and inventory scripts. Where it is not, require local sanitisation and use the supplied text artefacts. Produce Markdown, CSV, Mermaid, SVG or HTML outputs as supported.
